# ที่มาของภาพตัวละคร

ประกอบจากชิ้นส่วนของ **Tainara-P** สองชุด
- [Female Character Sprite Creator](https://tainara-p.itch.io/female-character-sprite-creator)
- [Male Character Sprite Creator](https://tainara-p.itch.io/male-character-sprite-creator)

ลิขสิทธิ์ **CC0 1.0** — ใช้ได้ทุกอย่างรวมถึงเชิงพาณิชย์ แก้ไขได้ ไม่ต้องให้เครดิต (แต่ให้ก็ดี)

ทั้งหกคนมาจากชุดเดียวกันโดยตั้งใจ ถ้าหยิบตัวละครสำเร็จจากหลายเจ้ามาผสม
จะได้หกลายเส้นซึ่งแย่กว่าของเดิมที่อย่างน้อยยังกลมกลืนกัน

ชิ้นส่วนที่เลือกของแต่ละคนอยู่ใน `data/looks.json`
ประกอบใหม่ด้วย `node tools/sprites.mjs build` (ต้องมีชุดต้นฉบับใน ~/Downloads)
